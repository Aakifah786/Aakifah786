🚀 Featured Projects

1. Idempotency Payment Gateway

A TypeScript-based backend payment gateway project designed to handle repeated payment requests safely and prevent duplicate charge creation.

Engineering Highlights

- Idempotent request handling: Uses idempotency keys to recognise repeated requests and replay stored results.
- Request integrity: Uses SHA-256 hashing of canonicalised request payloads to identify requests with matching or conflicting content.
- Conflict detection: Rejects reuse of an idempotency key with a different request payload.
- Recovery mechanisms: Implements processing tokens, recovery leases and handling for interrupted or uncertain processing outcomes.
- Persistent records: Uses PostgreSQL and Prisma to store idempotency keys, charges and processor transactions.
- Validation and testing: Includes request validation, automated tests and TypeScript build checks.

Tech Stack: TypeScript · Node.js · Express.js · PostgreSQL · Prisma ORM · Docker

🔗 "Explore the Repository" (https://github.com/Aakifah786/idempotency-payment-gateway)

Note: The project uses a simulated payment processor; it is not connected to a live payment provider.
